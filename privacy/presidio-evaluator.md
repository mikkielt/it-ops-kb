# presidio-evaluator (Presidio-Research)

## Summary
- The evaluation tooling is the `data-privacy-stack/presidio-research` repository, published on PyPI as `presidio-evaluator`. It is MIT-licensed, active, and not archived.
- Latest release is 0.3.2 (2026-08-04). It requires Python `>=3.11,<3.14`.

## Facts
- The Presidio docs point to Presidio-Research for evaluating the analyzer (precision, recall, F-beta; β=2 is recommended when recall matters), with notebooks for data generation and evaluation. [DOC S837]
