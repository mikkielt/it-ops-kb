# Autopilot digest

The autopilot's decisions the operator has not ratified, written by `python3 _tools/kbdecide.py digest`: the restricted classes first, each group oldest first. Ratify one with `python3 _tools/kbdecide.py ratify ID --by operator`, or revert it with `python3 _tools/kbdecide.py revert ID --by operator --why TEXT`.
