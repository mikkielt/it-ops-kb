# Alternatives: similar tools and how they differ

Tools that do part of what this kb does, what each overlaps with, how it differs, and its licence. Surveyed 2026-09-28: licences from each repository's GitHub `license` field and its `LICENSE` file, features from each project's README or official documentation, prices from the vendor's pricing page. A licence or a price is as current as that date; check the project before relying on it.

## What this project is, for the comparison

- **Stored, cited facts, not live pages.** One fact per line with a tag (`DOC`, `CODE`, `DER`, `COMMUNITY`, `UNK`) and source ids from a `_sources.csv` row that records url, publisher, licence and date (`kb/_self/content-rules.md`).
- **Deterministic retrieval with a stop rule.** `pack` is BM25 over a persisted index; it returns `good`, `weak` or `none` plus the lines and one url footer, and on `none` the agent states what the kb has and lacks, answers the part it has and takes the rest from the live docs, labelled, never from memory (`kb/_self/tools.md`, "How the lookup tools decide"). No embeddings, no reranker, no model in the lookup path.
- **Exact structural answers.** Counts, lists and "which lines cite this source" are tool calls (`audit`, `facts`, `src --cited`), not reading.
- **Upkeep by agents with evidence of freshness.** Skills research, refresh and census the sources; the fact diff settles unchanged facts without a model; a census tag marks a commit whose sources were all confirmed (`kb/_self/design.md`).
- **Ledgers of what is not known.** `_gaps.md` and `_conflicts.md` record what could not be confirmed and where sources disagree.
- **Domain.** Windows endpoint management (ConfigMgr, Intune, Autopilot, Entra ID, AD, Graph, GPO, Defender, DSC v3) and the agents that operate it, plus team roots beside `kb/public` (`kb/_self/plugin.md`).
- **Runs anywhere Python 3.11 runs.** Standard library only at run time, offline, a git repository as the store; the three live documentation servers in `AGENTS.md` are a fallback for what the kb lacks.
- **Licence.** Code Apache-2.0 (`LICENSE`), kb text CC BY 4.0 (`LICENSE-CONTENT`), snapshots and pinned files under their sources' licences (`NOTICE`).

## Tools compared

### Hosted documentation servers for agents

| tool | licence | overlap | difference |
|---|---|---|---|
| Microsoft Learn MCP Server (`learn.microsoft.com/api/mcp`) | repository CC-BY-4.0; the service is Microsoft's, free, no authentication | official Microsoft documentation for agents: search, fetch, code samples | live search over all of Learn, no stored facts, no verdict, no tags; answers cover every Microsoft product but not ConfigMgr community knowledge, other vendors or a team's own systems. This kb registers it as its live fallback |
| Context7 (Upstash) | MCP server MIT; the API backend, parsing and crawling engines are private | current library documentation injected into the agent's context | coding-library scope; hosted index built by the vendor; free tier with a monthly request limit, paid plans for private repositories |
| Ref (ref.tools) | MCP server MIT; the service is commercial | token-efficient documentation search and read (about 5k tokens a page, filtered by session history) | credit-billed: 1 credit per tool call, free tier 200 one-time credits, Pro $50 a month for 6,000; public and private library docs, no endpoint-management curation |
| DeepWiki MCP (Cognition) | proprietary service, free for public GitHub repositories, no authentication; `AsyncFuncAI/deepwiki-open` is an unaffiliated MIT reimplementation | model-generated wikis and question answering about a repository | answers are generated by a model from code, not cited facts from official documents; private repositories need a Devin account |
| GitMCP | Apache-2.0, free hosted or self-hosted | turns any GitHub repository's docs (`llms.txt`, README) into an MCP server | per-repository live docs; no curation, verdict or freshness record |

### Self-hosted documentation indexers

| tool | licence | overlap | difference |
|---|---|---|---|
| Grounded Docs MCP Server (`arabold/docs-mcp-server`) | MIT | a personal, version-specific index of documentation from websites, GitHub, npm, PyPI and local files, served over MCP | scrapes and chunks whole pages; semantic search needs an embedding provider (OpenAI, Ollama, Gemini, Azure); no fact tags or verdict |
| Docfork | MIT, repository archived | shareable SQLite documentation packages served by one `get_docs` tool | archived; library docs only |

### Local Markdown knowledge bases over MCP

| tool | licence | overlap | difference |
|---|---|---|---|
| qmd (`tobi/qmd`) | MIT | local Markdown search with BM25 and an MCP server | adds vector search and LLM reranking through local GGUF models (node-llama-cpp); searches notes, not tagged facts; no verdict or source ledger |
| knowledge-rag (`lyonzin/knowledge-rag`) | MIT | local RAG MCP server for Claude Code, BM25 plus semantic search | ONNX embeddings (FastEmbed), ChromaDB, cross-encoder reranking, many file formats; chunk retrieval, no provenance per fact |
| knowledge-base-mcp-server (`jeanibarz`) | Unlicense | Markdown folders searchable over MCP, lexical and dense search | FAISS index with a chosen embedding model (Ollama, OpenAI, HuggingFace) |
| Basic Memory | AGPL-3.0; hosted version commercial | Markdown files an agent reads and writes, a knowledge graph from wikilinks | a memory of conversations and notes, not verified documentation; AGPL obligations apply to a modified network service |

### RAG platforms

| tool | licence | overlap | difference |
|---|---|---|---|
| Onyx (formerly Danswer) | MIT outside `ee/` directories, which are under the Onyx Enterprise License | team search and chat over many connectors with source citations | a server application with a vector store and an LLM; indexes what it is given, does not research, verify or date sources |
| AnythingLLM | MIT | document chat, workspaces, agents, local or self-hosted | vector RAG on uploaded documents; no curation, no verdict, no gate |
| RAGFlow | Apache-2.0 | RAG engine with citations, strong document parsing | Elasticsearch-backed server stack; built for parsing hostile PDFs, not for a curated fact set |

### Endpoint-management specific

| tool | licence | overlap | difference |
|---|---|---|---|
| Security Copilot in Intune (agents and the Copilot features) | proprietary; needs Security Copilot enabled with security compute units (SCU) | natural-language help on Intune policies, settings, devices; agents for policy configuration, offboarding and vulnerability remediation | reads the tenant's live data and acts on it; no ConfigMgr, AD or GPO depth outside Intune; answers are not cited facts with source dates; billed per SCU |
| Intune Endpoint Management Skills (`imabdk/Intune-Endpoint-Management-Skills`) | MIT | agent skills for the Intune Endpoint security nodes, sourced from Microsoft Learn | procedures for GitHub Copilot in VS Code that send the agent to the Learn MCP server for facts; one Intune node so far, no stored facts, retrieval or upkeep tools |

## Differences by capability

| capability | this kb | nearest alternatives |
|---|---|---|
| provenance per fact (source row, publisher, licence, date, tag) | every fact line | none of the tools above; RAG platforms cite the chunk's document |
| answer without a model when covered | the `kb:` hook on a `good` pack | none; each returns text for a model to read |
| "not covered" as a first-class result | `none` verdict and a `_gaps.md` entry | none; search tools return their nearest hits |
| retrieval dependencies | Python standard library, persisted BM25 index | embedding models, vector stores, Elasticsearch, GGUF models or a hosted API |
| freshness evidence | source dates, anchored passages, fact diff, census tags | hosted services re-crawl on their own schedule; local indexers re-index on request |
| exact counts and joins | `audit`, `facts`, `src --cited` | none |
| Windows endpoint-management coverage beyond Intune | ConfigMgr, AD, GPO, DSC v3, Defender, Entra, Graph and more | Microsoft Learn MCP (live, uncurated), Security Copilot (Intune and security, live tenant) |
| a team's own systems beside vendor facts | extra roots in the same pack (`/kb-add-root`, `/kb-ingest`) | local indexers and RAG platforms index a team's files, without tags or verdict |
| cost per covered lookup | no API cost for the `kb:` hook; one tool call of 1-2k tokens in a session | per-call credits or seats (Context7, Ref), SCUs (Security Copilot), or local GPU/CPU for embeddings |

## Licensing compared

- **Permissive, reusable in any setting:** this kb's code (Apache-2.0), GitMCP and RAGFlow (Apache-2.0), qmd, knowledge-rag, AnythingLLM, docs-mcp-server, the Intune skills (MIT), knowledge-base-mcp-server (Unlicense).
- **Permissive client, closed service:** Context7 and Ref (MIT MCP servers in front of private backends), DeepWiki (closed, free for public repositories), Microsoft Learn MCP (repository CC-BY-4.0, service run by Microsoft).
- **Open core:** Onyx (MIT outside `ee/`, the Onyx Enterprise License inside).
- **Copyleft:** Basic Memory (AGPL-3.0: a modified version offered over a network must publish its source).
- **Proprietary:** Security Copilot.
- **Content:** this kb's text is CC BY 4.0, so a copy can be shared with attribution; its facts are written in its own words with quotes of 25 words or fewer, so the sources' licences are respected (`NOTICE`). The hosted services' indexes are theirs; what they return comes under each source's own terms.

## Why this project rather than one of them

- **The answer carries its evidence.** Each line says who published it, when it was confirmed and how it is known (`DOC` against `COMMUNITY` or `UNK`); the alternatives return pages, chunks or generated prose that the reader must trace back.
- **It says when it does not know.** The `none` verdict stops the agent from filling a gap from training data and sends it to the live docs for the lacking part; search tools always return something.
- **It is cheap and predictable per lookup.** A covered `kb:` question costs no model call, and a session lookup is one tool call of 1-2k tokens; the measured comparison against web search is in `kb/_self/design.md`. Hosted tools bill per call or seat, and local RAG tools need embedding and reranking models.
- **It runs with nothing to install and nothing to send out.** Standard-library Python, offline, a git clone as the store; no API key, vector store, Docker or GPU. Fits locked-down admin workstations and air-gapped networks.
- **It covers the domain as a whole.** ConfigMgr, AD, GPO and DSC v3 sit beside Intune, Entra and Graph, with a team's own roots in the same pack; the endpoint-management alternatives cover Intune (and Defender) only, and the generic ones cover no domain in particular.
- **Its freshness is checked, not assumed.** The fact diff, the census and the gate before every push keep the facts dated and consistent; the alternatives re-crawl or re-index without saying which facts changed.
- **Its licence allows any use.** Apache-2.0 code and CC BY 4.0 text, with no open-core split, copyleft or service terms.

## When another tool fits better

- **Any Microsoft product outside the kb, or the newest page:** Microsoft Learn MCP, which the kb already names as its live fallback.
- **Library and framework APIs for coding:** Context7, Ref, GitMCP or docs-mcp-server.
- **Understanding an unfamiliar public repository:** DeepWiki.
- **A tenant's live state or acting on it:** Security Copilot in Intune, or Graph through its own tools; this kb holds documentation facts, not device or directory data.
- **Semantic search over a large pile of unreviewed notes or PDFs:** qmd, knowledge-rag, AnythingLLM, RAGFlow or Onyx; the kb only holds facts someone researched and tagged.
