# Alternatives: similar tools and how they differ

Tools that do part of what this kb does, what each overlaps with, how it differs, and its licence. Surveyed 2026-09-28: licences from each repository's GitHub `license` field and its `LICENSE` file, features from each project's README or official documentation, prices from the vendor's pricing page. A licence or a price is as current as that date; check the project before relying on it.

## What this project is, for the comparison

- **Stored, cited facts, not live pages.** One fact per line with a tag (`DOC`, `CODE`, `DER`, `COMMUNITY`, `UNK`) and source ids from a `_sources.csv` row that records url, publisher, licence and date, or a `DECISION` tag naming an operator decision of the root's `_decisions.csv` (`kb/_self/content-rules.md`).
- **Deterministic retrieval with a stop rule.** `pack` is BM25 over a persisted index; it returns `good`, `weak` or `none` plus the lines and one url footer, and on `none` the agent states what the kb has and lacks, answers the part it has and takes the rest from the live docs, labelled, never from memory (`kb/_self/tools.md`, "How the lookup tools decide"). No embeddings, no reranker, no model in the lookup path.
- **Exact structural answers.** Counts, lists and "which lines cite this source" are tool calls (`audit`, `facts`, `src --cited`), not reading.
- **Upkeep by agents with evidence of freshness.** Skills research, refresh and census the sources; the fact diff settles unchanged facts without a model; a census tag marks a commit whose sources were all confirmed (`kb/_self/design.md`).
- **Ledgers of what is not known.** `_gaps.md` and `_conflicts.md` record what could not be confirmed and where sources disagree.
- **Domain.** Windows endpoint management (ConfigMgr, Intune, Autopilot, Entra ID, AD, Graph, GPO, Defender, DSC v3) and the agents that operate it, plus team roots beside `kb/public` (`kb/_self/plugin.md`).
- **Runs anywhere Python 3.11 runs.** Standard library only at run time, offline, a git repository as the store; the three live documentation servers in `AGENTS.md` are a fallback for what the kb lacks.
- **Licence.** Code Apache-2.0 (`LICENSE`), kb text CC BY 4.0 (`LICENSE-CONTENT`), snapshots and pinned files under their sources' licences (`NOTICE`).

## Differences by capability

| capability | this kb | nearest alternatives |
|---|---|---|
| provenance per fact (source row, publisher, licence, date, tag) | every fact line | none of the tools above; RAG platforms cite the chunk's document |
| answer without a model when covered | the `kb:` hook on a `good` pack (`backlog:` from `backlog.py`) | none; each returns text for a model to read |
| "not covered" as a first-class result | `none` verdict and a `_gaps.md` entry | none; search tools return their nearest hits |
| retrieval dependencies | Python standard library, persisted BM25 index | embedding models, vector stores, Elasticsearch, GGUF models or a hosted API |
| freshness evidence | source dates, anchored passages, fact diff, census tags | hosted services re-crawl on their own schedule; local indexers re-index on request |
| exact counts and joins | `audit`, `facts`, `src --cited` | none |
| Windows endpoint-management coverage beyond Intune | ConfigMgr, AD, GPO, DSC v3, Defender, Entra, Graph and more | Microsoft Learn MCP (live, uncurated), Security Copilot (Intune and security, live tenant) |
| a team's own systems beside vendor facts | extra roots in the same pack (`/kb-add-root`, `/kb-ingest`) | local indexers and RAG platforms index a team's files, without tags or verdict |
| cost per covered lookup | no API cost for the `kb:` hook; one tool call of 1-2k tokens in a session | per-call credits or seats (Context7, Ref), SCUs (Security Copilot), or local GPU/CPU for embeddings |

## Why this project rather than one of them

- **The answer carries its evidence.** Each line says who published it, when it was confirmed and how it is known (`DOC` against `COMMUNITY` or `UNK`); the alternatives return pages, chunks or generated prose that the reader must trace back.
- **It says when it does not know.** The `none` verdict stops the agent from filling a gap from training data and sends it to the live docs for the lacking part; search tools always return something.
- **It is cheap and predictable per lookup.** A covered `kb:` question costs no model call, and a session lookup is one tool call of 1-2k tokens; the measured comparison against web search is in `kb/_self/design.md`. Hosted tools bill per call or seat, and local RAG tools need embedding and reranking models.
- **It runs with nothing to install and nothing to send out.** Standard-library Python, offline, a git clone as the store; no API key, vector store, Docker or GPU. Fits locked-down admin workstations and air-gapped networks.
- **It covers the domain as a whole.** ConfigMgr, AD, GPO and DSC v3 sit beside Intune, Entra and Graph, with a team's own roots in the same pack; the endpoint-management alternatives cover Intune (and Defender) only, and the generic ones cover no domain in particular.
- **Its freshness is checked, not assumed.** The fact diff, the census and the gate before every push keep the facts dated and consistent; the alternatives re-crawl or re-index without saying which facts changed.
- **Its licence allows any use.** Apache-2.0 code and CC BY 4.0 text, with no open-core split, copyleft or service terms.

## When another tool fits better

- **Any Microsoft product outside the kb, or the newest page:** Microsoft Learn MCP, which the kb already names as its live fallback.
- **Library and framework APIs for coding:** Context7, Ref, GitMCP or docs-mcp-server.
- **Understanding an unfamiliar public repository:** DeepWiki.
- **A tenant's live state or acting on it:** Security Copilot in Intune, or Graph through its own tools; this kb holds documentation facts, not device or directory data.
- **Messages and file reservations between agents of several vendors:** MCP Agent Mail, subject to its rider; **a dependency graph of tasks for agents:** Beads; **many agents run and supervised from one workspace:** Gas Town, or Herdr for terminal panes and their states; **a lead session directing teammates inside Claude Code:** its agent teams. The kb sits beside them as the source of cited facts and as this clone's own tracker and coord store.
- **Semantic search over a large pile of unreviewed notes or PDFs:** qmd, knowledge-rag, AnythingLLM, RAGFlow or Onyx; the kb only holds facts someone researched and tagged.
