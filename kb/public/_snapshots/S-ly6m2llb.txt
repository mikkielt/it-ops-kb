Adds a new PowerShell function, Export-OSConfigDiagnostics, to gather diagnostics. It collects key registry entries, event logs, and directory contents, while also running diagnostic scripts for module and configuration information. All the gathered data is then compressed into a ZIP file for easy analysis.
