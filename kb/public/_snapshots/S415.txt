Update runner docs to capture details on gMSA support
## Overview
In this [issue](https://gitlab.com/gitlab-org/gitlab-runner/-/issues/27895) support for Microsoft Group Managed Service Accounts (gMSA) was added to the runner docker executor with this [community contribution](https://gitlab.com/gitlab-org/gitlab-runner/-/merge_requests/2913) from @Jamesits. We need to revise the runner docs so its a bit more clear how to use this feature with Microsoft Group Managed Service Accounts (gMSA).
