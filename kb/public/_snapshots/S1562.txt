## Latest Updates
Available for public comment: CSF 2.0 Community Profile for Federal Agency Open Radio Access Network (O-RAN) Deployment. This draft CSF 2.0 profile describes how components that conform to the security specifications produced by the O-RAN ALLIANCE support various CSF 2.0 outcomes.
The final version of CSF 2.0 Informative References Quick‑Start Guide has published. This document explains how to find, filter, and apply informative references using NIST tools. The document also provides two sample use cases along with examples of how artificial intelligence (AI) tools can support reference data use when implemented with continuous evaluation and improvement.
Available for public comment: CSF 2.0 Quick-Start Guide for Using Artificial Intelligence (AI) for CSF Analysis and Reporting. This draft quick-start guide illustrates practical and actionable ways AI could be used for analyzing, planning, implementing, and monitoring an organization’s progress toward achieving CSF 2.0 outcomes. The comment period closes October 15.
