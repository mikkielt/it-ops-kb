# Snapshots of `copy` sources

Each `<id>.txt` here is the normalized text of one live source of this root whose `reuse` class in `_sources.csv` is `copy` (an open licence allows a verbatim copy with attribution), written by `python3 _tools/factdiff.py snapshot` and updated by `factdiff.py detect` when the source changes, so git holds its history and a diff shows what changed.

- **Licence.** Each file is under the licence its header names (MIT, CC BY 4.0, CC BY-SA 4.0, ...), not under this repository's licence. A share-alike file (CC BY-SA) stays under CC BY-SA wherever it is copied.
- **Attribution.** The header names the source id, url, title, publisher, licence and the date the text was taken, and states the changes: the text was normalized (front matter, link targets, images and page chrome removed).
- **Not kb content.** The lookup tools, the index and the checks skip this directory; facts cite the source row, never a snapshot.
