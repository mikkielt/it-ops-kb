# Supported agents

Docker Sandboxes runs the following agents in local sandboxes:

- Claude Code
- Codex
- Copilot
- Cursor
- Devin
- Docker Agent
- Droid
- Gemini
- Kiro
- OpenCode
- Shell — agent-less sandbox for manual setup or testing

Want to pre-install tools or customize an agent's environment?
See Customize.
