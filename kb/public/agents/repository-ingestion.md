# Reading a repository into a knowledge base: generated and vendored files

## Summary
When an agent turns a repository into facts, generated and vendored files are the ones to leave out: nobody on
the team wrote them, and a fact read from them describes a tool's output or someone else's library. Repositories
say which files those are in `.gitattributes`: GitHub Linguist's `linguist-generated` and `linguist-vendored`, and
GitLab's `gitlab-generated`. `git check-attr` reads those attributes at a given commit, and Go marks generated
source with a fixed header line. This kb's `/kb-ingest` skill and `_tools/kbingest.py` apply these signals.

## Facts
- Linguist reads the `linguist-documentation`, `linguist-language`, `linguist-vendored`, `linguist-generated` and `linguist-detectable` attributes from a repository's `.gitattributes`, with git-style path patterns relative to the `.gitattributes` file's position. [DOC S-czqctq3z]
- Linguist excludes files marked `linguist-generated` from language statistics and hides them in diffs; files marked `linguist-vendored` or `linguist-documentation` are excluded from statistics only. [DOC S-czqctq3z]
- Linguist treats every path in its `vendor.yml` as vendored and every path in its `generated.rb` as generated by default; a `.gitattributes` line with `-linguist-vendored` or `-linguist-generated` un-marks a path (`jquery.js -linguist-vendored`). [DOC S-czqctq3z]
- Linguist applies attributes added to `.gitattributes` only once that file is committed. [DOC S-czqctq3z]
- GitLab collapses generated files in merge request diffs by default (Free, Premium, Ultimate; GitLab.com, Self-Managed, Dedicated): `.nib`, `.xcworkspacedata` and `.xcuserstate` files, package lock files (`package-lock.json`, `Gopkg.lock`), files in `node_modules`, minified `js` or `css`, source map files, and generated Go files including protocol buffer output. [DOC S-rhxv4cuv]
- GitLab marks a further file or path as generated with the `gitlab-generated` attribute in `.gitattributes` (`docs/** gitlab-generated`), and `-gitlab-generated` stops a default from collapsing (`package-lock.json -gitlab-generated`); the change applies once merged into the default branch. [DOC S-rhxv4cuv]
- GitLab points to the `go-enry` project's `generated.go` for how it detects generated files. [DOC S-rhxv4cuv]
- `git check-attr` reports, for each path and attribute, `unspecified`, `unset` (defined as false), `set` (defined as true) or the assigned value. [DOC S-drdhmn2b]
- `git check-attr --source=<tree-ish>` checks attributes against a commit, branch or tag instead of the working tree; `--stdin` reads the paths from standard input, and with `-z` both input paths and the `<path> NUL <attribute> NUL <info> NUL` output are NUL-separated. [DOC S-drdhmn2b]
- `--cached` makes `git check-attr` consider only the `.gitattributes` in the index, ignoring the working tree. [DOC S-drdhmn2b]
- Go's convention: generated source should have a line matching `^// Code generated .* DO NOT EDIT\.$` before the first non-comment, non-blank text of the file, to tell people and tools that the code is generated. [DOC S-me5pwvu4]
- An agent that ingests a repository can therefore skip a file when `git check-attr --source=<commit>` reports `linguist-generated`, `gitlab-generated` or `linguist-vendored` as `set`, keep it when the attribute is `unset` (an explicit override of a default), and fall back to the Linguist and GitLab default lists (lock files, minified files, source maps, `node_modules`, vendor directories) and Go's header line when it is `unspecified`. [DER S-czqctq3z, S-rhxv4cuv, S-drdhmn2b, S-me5pwvu4: combines the attribute semantics, the default lists and the header convention]

## Examples
- SNIPPET: `.gitattributes` lines that mark a generated client and a vendored library, and keep one lock file visible; context: a repository on GitLab or GitHub, attributes take effect once committed; checked: no [DER S-czqctq3z, S-rhxv4cuv: attribute names and the `-attr` form from both pages]
```gitattributes
src/api_client/** linguist-generated gitlab-generated
third_party/** linguist-vendored
package-lock.json -gitlab-generated
```
- SNIPPET: list the three attributes for every file of a commit, NUL-separated; context: git 2.40 or later for `--source`, run in the repository; checked: no [DOC S-drdhmn2b]
```sh
git ls-tree -r -z --name-only <commit> | git check-attr --stdin -z --source=<commit> linguist-generated linguist-vendored gitlab-generated
```
