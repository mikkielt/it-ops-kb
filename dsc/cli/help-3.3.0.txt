===== dsc  --help
Apply configuration or invoke specific DSC resources

Usage: dsc [OPTIONS] <COMMAND>

Commands:
  completer  Generate a shell completion script
  config     Apply a configuration document
  extension  Operations on DSC extensions
  function   Operations on DSC functions
  server     Use DSC as a server over JSON-RPC (useful as MCP server)
  resource   Invoke a specific DSC resource
  schema     Get the JSON schema for a DSC type
  help       Print this message or the help of the given subcommand(s)

Options:
  -l, --trace-level <TRACE_LEVEL>
          Trace level to use
          
          [possible values: error, warn, info, debug, trace]

  -t, --trace-format <TRACE_FORMAT>
          Trace format to use
          
          [possible values: default, plaintext, json]

  -p, --progress-format <PROGRESS_FORMAT>
          Progress format to use

          Possible values:
          - default: If interactive, use a progress bar. If not interactive, no progress is shown
          - none:    No progress is shown
          - json:    Show progress as JSON

      --ignore-settings-file
          Ignore the settings file when running the command

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
===== dsc config --help
Apply a configuration document

Usage: dsc config [OPTIONS] <COMMAND>

Commands:
  get     Retrieve the current configuration
  set     Set the current configuration
  test    Test the current configuration
  export  Export the current configuration
  help    Print this message or the help of the given subcommand(s)

Options:
  -p, --parameters <PARAMETERS>
          Parameters to pass to the configuration as JSON or YAML
  -f, --parameters-file <PARAMETERS_FILE>
          Parameters to pass to the configuration as a JSON or YAML file
  -r, --system-root <SYSTEM_ROOT>
          Specify the operating system root path if not targeting the current running OS
  -h, --help
          Print help

===== dsc resource --help
Invoke a specific DSC resource

Usage: dsc resource <COMMAND>

Commands:
  list    List or find resources
  get     Invoke the get operation to a resource
  set     Invoke the set operation to a resource
  test    Invoke the test operation to a resource
  delete  Invoke the delete operation to a resource
  schema  Get the JSON schema for a resource
  export  Retrieve all resource instances
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
===== dsc resource list --help
List or find resources

Usage: dsc resource list [OPTIONS] [RESOURCE_NAME]

Arguments:
  [RESOURCE_NAME]  Optional resource name to filter the list [default: *]

Options:
  -a, --adapter <ADAPTER_NAME>         Adapter filter to limit the resource search
  -d, --description <DESCRIPTION>      Description keyword to search for in the resource description
  -t, --tags <TAGS>                    Tag to search for in the resource tags
  -o, --output-format <OUTPUT_FORMAT>  The output format to use [possible values: json, pretty-json, yaml, table-no-truncate]
  -h, --help                           Print help
===== dsc resource get --help

  -a, --all                            Get all instances of the resource

  -v, --version <VERSION>              The version of the resource to invoke in semver format

  -o, --output-format <OUTPUT_FORMAT>  The output format to use [possible values: json, json-array, pass-through, pretty-json, yaml]
  -h, --help                           Print help
